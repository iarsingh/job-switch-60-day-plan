# Resume And LinkedIn Checklist

## Resume

- One-page or two-page max, depending on experience density.
- Summary targets DevOps, MLOps, Cloud, Platform roles.
- Top skills include:
  - Kubernetes
  - Docker
  - Terraform
  - GCP
  - CI/CD
  - Python
  - Prometheus/Grafana
  - Linux
  - Ansible
  - MLflow / Vertex AI if applying for MLOps
- Each experience bullet has impact:
  - reduced deployment time
  - improved reliability
  - automated manual work
  - reduced cost
  - improved monitoring
  - handled scale or incidents

## Strong Bullet Formula

`Built/Automated/Improved <system> using <tools>, resulting in <business/engineering impact>.`

Examples:

- Built CI/CD pipelines using GitHub Actions, Docker, and GKE, reducing manual deployment effort by 70%.
- Automated infrastructure provisioning with Terraform modules for VPC, IAM, and GKE, improving environment consistency across dev and prod.
- Implemented Prometheus and Grafana dashboards for service latency, error rate, and resource saturation, reducing incident triage time.

## LinkedIn

Headline:

`DevOps / MLOps Engineer | Kubernetes | GCP | Terraform | CI/CD | Observability | AI Infrastructure`

About section should include:

- years of experience
- target roles
- strongest tools
- project proof
- current availability with 60-day notice period

Featured section:

- Resume PDF
- GitHub portfolio
- MLOps incident copilot project
- Terraform/GKE project
